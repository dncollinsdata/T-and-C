================================================================================
T&C INTEGRITY — DIVI 5 DESIGN SYSTEM IMPORT ORDER
================================================================================

Import these files IN THIS ORDER on a clean Divi 5 site.
Importing out of order may cause missing style references.

================================================================================
STEP 1: Import Global Variables
================================================================================
File: TC-Integrity_Global-Variables.json
Where: Divi → Divi Library → Import & Export
Enable: "Import Global Variables" checkbox
What it does: Sets up all brand colors, fonts, spacing, radius,
              and string variables (phone, email, CTA text, etc.)

================================================================================
STEP 2: Import Theme Customizer Settings
================================================================================
File: TC-Integrity_Theme-Customizer.json
Where: Divi → Theme Customizer → ↑↓ (Import/Export arrows)
What it does: Sets baseline typography (Montserrat headings,
              Open Sans body), nav styles, button styles, footer
              colors, and the 8-color brand palette.

================================================================================
STEP 3: Build Pages Manually in Divi 5 Visual Builder
================================================================================
Use the content files in page-content/ as your copy-paste reference:

  01-homepage.txt         → Create "Home" page
  02-services.txt         → Create "Services" page
  03-about.txt            → Create "About" page
  04-contact.txt          → Create "Contact" page
  05-service-area-template.txt + 05a through 05i → Create 9 city pages

Each file tells you:
  - What Divi module to add (Text, Blurb, CTA, Accordion, etc.)
  - What content to paste into it
  - What colors/fonts/spacing to apply (use your global variables!)

TIP: When setting colors in the Divi 5 builder, click the globe icon
to reference your Global Variables instead of typing hex codes. This
way, changing a variable later updates every module that uses it.

================================================================================
AFTER IMPORT: What to Customize First
================================================================================

1. Upload your logo: Divi → Theme Options → General → Logo
2. Replace placeholder phone/email in Global Variables:
   - Change (555) 123-4567 → your real number
   - Change info@tcintegritytrash.com → your real email
   - Change tel:+15551234567 → your real phone link
3. Build pages using the Visual Builder + content files
4. Upload real photos (team, truck, before/after)
5. Set up navigation menu (Appearance → Menus)
6. Install Yoast SEO and paste meta titles/descriptions from city files
