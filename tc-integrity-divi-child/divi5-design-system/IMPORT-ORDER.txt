================================================================================
T&C INTEGRITY — DIVI 5 DESIGN SYSTEM — FULL IMPORT GUIDE
================================================================================

All files now use the Divi 5.2.1 native format (context: et_builder_layouts)
with WordPress block comments (<!-- wp:divi/... -->).

Files:
  divi5-design-system/
    TC-Integrity_Global-Variables.json  → Colors, fonts, spacing, strings
    TC-Integrity_Presets.json           → Module presets (reference only*)
    TC-Integrity_Theme-Customizer.json  → Baseline WP theme settings
    TC-Integrity_Theme-Builder-Templates.json → Header/footer build reference

  divi5-layouts/
    TC-Integrity_Pages.json → Homepage, Services, About, Contact
                              (ALSO includes global_colors + global_variables)

* The Presets file uses the old context format. If it won't import,
  the presets are documented below for manual creation in the builder.

================================================================================
STEP 1: Import Global Variables + Page Layouts (one file!)
================================================================================
File: divi5-layouts/TC-Integrity_Pages.json
Where: Divi → Divi Library → Import & Export
Enable: BOTH "Import Global Variables" AND regular import checkboxes

What it does (all in one import):
  - Creates 4 library layouts: Homepage, Services, About, Contact
  - Loads 15 global colors into your Divi color picker
  - Loads 40 global variables (fonts, sizes, spacing, strings, links)

If you prefer to import variables separately (without layouts):
  File: divi5-design-system/TC-Integrity_Global-Variables.json
  Same location, enable "Import Global Variables"

================================================================================
STEP 1b (optional): Import Presets
================================================================================
File: TC-Integrity_Presets.json
Where: Divi → Divi Library → Import & Export
Enable: "Import Presets" checkbox

What it does: Loads 21 pre-configured module presets so every module
you add to a page is already styled with T&C branding:

  BUTTONS (4 presets):
    - TC Primary Button (green bg, white text, pill shape) — DEFAULT
    - TC Outline Button White (for dark backgrounds)
    - TC Outline Button Green (for light backgrounds)
    - TC Gold CTA Button (premium accent)

  TEXT (3 presets):
    - TC Body Text (Open Sans 16px, Montserrat headings) — DEFAULT
    - TC Section Heading (centered, 36px h2, muted subtitle)
    - TC White Text (for dark green sections)

  BLURBS (3 presets):
    - TC Service Card Blurb (icon top, shadow card) — DEFAULT
    - TC Blurb with Circle Icon (green circle, white icon)
    - TC Nearby City Link Blurb (for service area interlinking)

  OTHER MODULES:
    - TC Green CTA Banner (transparent bg, white text) — DEFAULT
    - TC Testimonial Card (shadow card, styled author) — DEFAULT
    - TC FAQ Accordion (green toggles, bordered) — DEFAULT
    - TC Stats Counter (white numbers on green) — DEFAULT
    - TC Contact Form (rounded fields, green button) — DEFAULT
    - TC Hero Header (green overlay, dual buttons) — DEFAULT
    - TC Image Card (8px radius, shadow) — DEFAULT

  SECTIONS (4 presets):
    - TC Section White (80px padding) — DEFAULT
    - TC Section Light Green (#f5f9f3)
    - TC Section Dark Green Gradient (135deg)
    - TC Stats Counter Section (50px padding)

Presets marked DEFAULT auto-apply when you add that module type.


================================================================================
STEP 2: Import Global Variables
================================================================================
File: TC-Integrity_Global-Variables.json
Where: Divi → Divi Library → Import & Export
Enable: "Import Global Variables" checkbox

What it does: Sets up all brand tokens:
  - 15 global colors (palette swatches)
  - 11 color variables, 2 font variables
  - 20 number variables (typography sizes, spacing scale, radii)
  - 8 string variables (company name, phone, email, CTA text, hours)
  - 5 link variables (site URL, contact page, phone link, email link)


================================================================================
STEP 3: Import Theme Customizer Settings
================================================================================
File: TC-Integrity_Theme-Customizer.json
Where: Divi → Theme Customizer → ↑↓ (Import/Export arrows)

What it does: Sets WordPress-level theme settings:
  - Navigation: 80px height, Montserrat bold uppercase, #1a2e1a text
  - Typography: Montserrat headings + Open Sans 16px body
  - Buttons: #4CAF50 bg, white text, 50px pill radius, uppercase
  - Footer: #1B5E20 bg, white headings, #81C784 links
  - 8-color brand palette in Divi color picker
  - Mobile menu: #1B5E20 bg with white text


================================================================================
STEP 4: Build Header & Footer in Theme Builder
================================================================================
Reference: TC-Integrity_Theme-Builder-Templates.json
Where: Divi → Theme Builder

This file now uses Divi 5 native block format (<!-- wp:divi/... -->)
with full header and footer markup in the post_content fields.

The header and footer post_content can be used as reference when
building in Divi > Theme Builder, or copied directly into the
WordPress editor's Code view.

HEADER (Global Header) includes:
  Section 1 — Top Utility Bar (#1B5E20, 8px padding)
    Left:  "Mon-Sat: 7AM - 7PM" (white text, 14px)
    Right: Phone link "(555) 123-4567 — Free Estimates" (#81C784)
  Section 2 — Main Navigation (#ffffff, box shadow)
    Left:  Logo image (54px max height)
    Right: Menu module (primary-menu, Montserrat bold uppercase)

FOOTER (Global Footer) includes:
  Section 1 — Footer Main (#1B5E20, 60px/40px padding)
    4-column row: Company info, Services links, Service Areas, Contact
  Section 2 — Bottom Bar (#0d1f0d, 20px padding)
    Left: Copyright | Right: Privacy Policy / Terms links

After building, assign this as the Default Website Template.


================================================================================
STEP 5: Build Pages in Visual Builder
================================================================================
Use the content files in page-content/ as your copy-paste reference:

  01-homepage.txt         → Create "Home" page
  02-services.txt         → Create "Services" page
  03-about.txt            → Create "About" page
  04-contact.txt          → Create "Contact" page
  05-service-area-template.txt + 05a through 05i → Create 9 city pages

Each file tells you:
  - What Divi module to add (Text, Blurb, CTA, Accordion, etc.)
  - What content to paste into it
  - Which preset to select (they should auto-apply as defaults)
  - What colors/fonts/spacing to apply

TIPS:
  - Presets auto-apply! When you add a Button, it's already green pill
  - Click the globe icon to reference Global Variables for colors
  - For sections, pick a Section Preset (white, light, or dark gradient)
  - Clone your first city page to save time on the other 8


================================================================================
STEP 6: Final Setup
================================================================================

1. Upload your logo: Divi → Theme Options → General → Logo
2. Replace placeholder phone/email in Global Variables:
   Divi → Divi Library → click a variable → edit value
   - Change (555) 123-4567 → your real number
   - Change info@tcintegritytrash.com → your real email
   - Change tel:+15551234567 → your real phone link
3. Set up navigation: Appearance → Menus → create "Primary Menu"
4. Set homepage: Settings → Reading → Static page → "Home"
5. Upload real photos (team, truck, before/after)
6. Install Yoast SEO, paste meta titles/descriptions from city files
7. Test mobile responsiveness
8. Test Google Rich Results (schema from child theme functions.php)
